# برنامج العقدة (Firmware) — ESP32

الملف: [`sensor_node/sensor_node.ino`](sensor_node/sensor_node.ino)

يقرأ الحساسات، ويحدد حالة كل قطعة، ويعرض القيم على الشاشة، ويرسل رسالة JSON
دورية بالطريقتين معًا: HTTP عبر الواي فاي، وسطر `DATA:` على منفذ USB.

> ⚠ **هذا البرنامج لم يُختبر على العتاد بعد.** راجع أرقام المنافذ على الطباعة
> الموجودة على لوحتك قبل التوصيل، واتبع خطة الاختبار المرحلية: حساس واحد في كل مرة.

---

## 1. إعداد بيئة Arduino

| العنصر | الاختيار |
|---|---|

## 3. ما يجب تعديله قبل الرفع

كل الإعدادات في **قسم واحد** أعلى الملف تحت عنوان «FW-12». عدّل هذه فقط:

```cpp
const char* WIFI_SSID  = "ضع_اسم_الشبكة_هنا";
const char* WIFI_PASS  = "ضع_كلمة_المرور_هنا";
const char* SERVER_URL = "http://192.168.1.50:5000/api/readings";
const char* NODE_ID    = "node-01";
```

**عنوان الخادم** يطبعه الخادم نفسه عند تشغيله جاهزًا للنسخ، ويظهر أيضًا في
قسم «أدوات» أسفل اللوحة.

**الشبكة يجب أن تكون 2.4 GHz** — ESP32 لا يدعم 5 GHz. في بعض الجوالات يوجد
خيار «توسيع التوافق» أو «2.4 GHz» في إعدادات الهوتسبوت.

### الكرة الحرارية (مؤجلة)

```cpp
#define ENABLE_GLOBE 0     // 1 لإعادة تفعيل الكرة الحرارية
```

مؤجلة في الإصدار 2 لأن التقييم داخل القاعة. عند إطفائها تُرسل `ds18b20`
و`battery` بحالة `disabled`، ويفترض الخادم MRT مساوية لحرارة الهواء.
لإعادتها: شغّل هذا المفتاح، ثم حوّل `mrt_source` إلى `"globe"` في `config.json`.

### فترة الإرسال

```cpp
const bool TEST_MODE = true;   // true: كل 5 ثوانٍ · false: كل 60 ثانية
```

### معايرة الرياح

```cpp
const float K_WIND = 20.0f;    // قيم مؤقتة حتى المعايرة
const float B_WIND = 0.5f;
const float V_MIN  = 0.02f;
```

لست مضطرًا لإعادة الرفع بعد كل معايرة: الخادم يعيد حساب سرعة الرياح من الجهد
الخام بمعاملاته المحفوظة (SV-15)، وتُدخل من نموذج المعايرة في اللوحة.

## 4. المنافذ

| المنفذ | يوصل إلى |
|---|---|
| GPIO 4 | DATA في DHT22 |
| GPIO 13 | DATA في DS18B20 — مؤجل، عند `ENABLE_GLOBE` فقط |
| GPIO 21 | SDA المشترك (ADS1115، MLX90614، BH1750) |
| GPIO 22 | SCL المشترك |
| GPIO 18 | CLK في الشاشة |
| GPIO 23 | DIN في الشاشة |
| GPIO 5 | CS في الشاشة |
| GPIO 16 | DC في الشاشة |
| GPIO 17 | RST في الشاشة |
| GPIO 32 | BL إضاءة الشاشة (PWM) |
| VIN | غير مستخدم — التغذية من منفذ USB مباشرة |

تفاصيل التوصيل الكاملة في [../05_docs/جدول-التوصيل.md](../05_docs/جدول-التوصيل.md).

**منافذ ممنوعة:** GPIO 6 إلى 11 (محجوزة للذاكرة)، وGPIO 34 إلى 39 (إدخال فقط).

## 6. سلوك البرنامج

| المهمة | التكرار |
|---|---|
| عينة جهد الموتور | كل 100 ملي ثانية، ويُرسل متوسطها |
| DHT22 | كل 5 ثوانٍ، ولا أسرع من مرة كل ثانيتين |
| DS18B20 | كل 5 ثوانٍ بتحويل غير حاجز (يُطلب ثم يُقرأ بعد 800 ملي ثانية) |
| MLX90614 وBH1750 والبطارية | كل 5 ثوانٍ |
| الشاشة | كل ثانيتين |
| الإرسال | كل 5 ثوانٍ (وضع الاختبار) |

**لا يوجد `delay()` في الحلقة الرئيسية** (FW-09): كل مهمة لها جدولتها بـ `millis()`،
حتى لا يتوقف قياس الرياح أثناء انتظار حساس آخر.

**إن فشل الواي فاي** (FW-08): يستمر القياس والطباعة على USB، ويحاول إعادة الاتصال
كل 30 ثانية دون أن يتوقف. استخدم جسر USB في هذه الحالة.

## 7. الشاشة

تعرض UTCI بخط كبير على خلفية بلون فئة الإجهاد، وتحتها حرارة الهواء والرطوبة
وحرارة الكرة والرياح والبطارية، وحالة الواي فاي.

قيمة UTCI تأتي **من رد الخادم** (FW-11)، لأن العقدة لا تحسبها (DS-04).
قبل وصول أول رد تظهر `--.-` وهذا طبيعي.

> العناوين على الشاشة بالإنجليزي لأن مكتبة Adafruit GFX لا تحتوي حروفًا عربية.
> لون الشريط يأتي من مفتاح الفئة الذي يرجعه الخادم (`stress_key`).

## 8. مشكلات شائعة

| المشكلة | الحل |
|---|---|
| الشاشة بيضاء | راجع توصيل DC وRST، وتأكد من `init(240, 280)` |
| ألوان الشاشة معكوسة | جرّب `tft.invertDisplay(true)` أو `false` |
| `عدد مجسات DS18B20: 0` | مقاومة 4.7kΩ مفقودة — عند تفعيل الكرة فقط |
| DHT22 يرجع NaN | لا تقرأه أسرع من كل ثانيتين؛ وتحقق من مقاومة 10kΩ إن كان مجردًا |
| `ADS1115 غير موجود` | تحقق من SDA وSCL ومن توصيل ADDR بـ GND |
| `VEML7700 غير موجود` | العنوان 0x10: تحقق من VIN وSDA وSCL ولحام الأطراف |
| الشاشة مزاحة أو مقصوصة | ضبط `setRowColStart` حسب وحدتك، أو `init(240, 280, SPI_MODE2)` |
| جهد الموتور سالب | اعكس سلكي الموتور |
| إعادة تشغيل متكررة | `BROWNOUT` يعني مشكلة طاقة: غيّر كابل USB أو المنفذ، أو استخدم منفذًا مغذّى |
| فشل الرفع | أنزل سرعة الرفع إلى 115200، واضغط زر BOOT أثناء بدء الرفع |
