# أدوات مساعدة

## `send_test_message.py` — إرسال رسالة اختبار

يتأكد أن الخادم يستقبل ويحسب **قبل** توصيل ESP32 إطلاقًا.
الرسالة مطابقة تمامًا لما يبنيه برنامج العقدة (schema 2).

```bash
python3 06_tools/send_test_message.py
python3 06_tools/send_test_message.py --server http://localhost:5000 --node node-test
python3 06_tools/send_test_message.py --missing bh1750 mlx90614    # محاكاة قطع مفقودة
python3 06_tools/send_test_message.py --error dht22                # محاكاة قراءة خاطئة
python3 06_tools/send_test_message.py --repeat 20 --interval 2     # سلسلة لاختبار الرسوم
```

## `acceptance_test.py` — اختبار معايير القبول

يشغّل خادمًا مستقلًا على منفذ اختبار (5099)، ويفحص كل بنود القسم 12 آليًا،
ثم يطبع تقريرًا ويعيد الإعدادات كما كانت. لا يمس قاعدة بيانات العمل.

```bash
python3 06_tools/acceptance_test.py
```

يفحص 29 بندًا، منها:

- بطاقة لكل قطعة من الجدول 3.1 بحالتها الصحيحة
- فصل حساس يحوّل بطاقته لحالة خطأ مع رسالة مساعدة
- إطفاء العقدة يجعلها «غير متصلة»
- حساب UTCI وفئته وMRT والرياح عند 10 م وعلامة «رياح مقيّدة»
- الطريقتان: واي فاي وUSB
- وضع المحاكاة ومحاكاة الأعطال
- تصدير CSV بأعمدة واضحة وعمود حالة لكل قطعة
- رفض الرسالة المعطوبة بسبب واضح وتسجيلها
- قبول الحقول غير المعروفة وتجاهلها (DS-06)
- إعادة حساب الرياح بمعاملات المعايرة (SV-15)
- أن الصفحة لا تطلب أي ملف من الإنترنت (UI-02)

شغّله بعد أي تعديل على الخادم للتأكد أن شيئًا لم ينكسر.
