## إضافات خارج نص المتطلبات

أُضيفت لأن الفريق طلبها، ولا تتعارض مع أي معرّف:

| الإضافة | السبب |
|---|---|
| المفتاح الواحد `mrt_source` | معيار القبول الجديد ينص على تفعيل الكرة بإعداد واحد؛ فجعلناه يقود كل شيء: البطاقة والفحوص والتصحيح والقيم الأساسية |
| مفتاح وضعين: العتاد الحقيقي والمحاكاة | فصل قاطع بين القراءات الحقيقية والوهمية أثناء التجميع |
| حالة عرض `not_connected` «غير متصل» | في وضع العتاد قبل وصول أول رسالة، تظهر كل البطاقات بدل صفحة فارغة. حالة عرض فقط، ولا ترسلها العقدة، فالحالات السبع في الجدول 3.2 باقية كما هي |
| معرّفات `sim-01` و`sim-02` لعقد المحاكاة | تمنع اختلاط بيانات المحاكاة ببيانات `node-01` الحقيقية في قاعدة البيانات والرسوم |
| انتقال تلقائي لمنفذ بديل | المنفذ 5000 يحجزه «مستقبل AirPlay» على ماك |
