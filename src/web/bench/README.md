# لوحة العرض

صفحة واحدة بالعربية من اليمين لليسار، يقدمها الخادم على `http://localhost:5000`.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | بنية الصفحة: شريط العقدة، وبطاقة UTCI، والبطاقات، والتنبيهات، والرسوم، والتشخيص، والأدوات |
| `css/style.css` | التنسيق وألوان الحالات وفئات UTCI ووضع العرض والجوال |
| `js/app.js` | جلب البيانات كل ثانيتين، وبناء البطاقات، وأزرار الأدوات |
| `js/charts.js` | رسوم الخطوط الصغيرة على canvas، مكتوبة يدويًا |
| `favicon.svg` | أيقونة الصفحة |

## لا إنترنت إطلاقًا

لا توجد أي مكتبة رسوم، ولا أي خط من الشبكة، ولا CDN.
الرسوم مكتوبة يدويًا على `canvas`، والخطوط من خطوط النظام المثبّتة
على ويندوز وماك. هذا شرط لأن الشبكة في مكان العرض قد لا تكون متصلة بالإنترنت.

اختبار هذا الشرط آلي ضمن `06_tools/acceptance_test.py`.

## الألوان لا تكفي وحدها

كل شارة حالة فيها **الكلمة واللون معًا** (مثل «يعمل» و«غير موجود»)،
لمن لا يميز الألوان.

## الوضعان

مفتاح أعلى الصفحة يبدّل بين **🔌 العتاد الحقيقي** و**🧪 المحاكاة**،
ويظهر شريط تحت الشريط العلوي يوضح الوضع الحالي وما يعنيه.

في وضع العتاد الحقيقي: تُخفى عقد المحاكاة تمامًا، وقبل وصول أول رسالة
تظهر كل البطاقات بحالة «غير متصل» مع رسالة المساعدة، بدل صفحة فارغة.

## أزرار مهمة

| الزر | الوظيفة |
|---|---|
| **وضع العرض** | يكبّر بطاقة UTCI والقيم الأساسية، ويخفي التشخيص والأدوات — أمام اللجنة |
| **إيقاف التحديث** | يجمّد اللوحة للتصوير أو القراءة المتأنية |
| **اختيار العقدة** | يبدّل بين العقد، ويظهر لون نقطة الاتصال في القائمة |
| **مفتاح الوضع** | عتاد حقيقي (يخفي المحاكاة) أو محاكاة (بيانات وهمية) |
| **تصدير CSV** | يصدّر كل البيانات أو آخر فترة محددة |

## التحديث

- القيم والحالات: كل **ثانيتين** بلا إعادة تحميل الصفحة.
- الرسوم والمحاكاة وحالة الخادم: كل **5 ثوانٍ**.
- عند انقطاع الخادم يظهر شريط أحمر أعلى الصفحة بدل تجمّد القيم.

فترة التحديث تُضبط من `config.json` في `timing.dashboard_refresh_ms`.

## من الجوال

افتح من أي جهاز على نفس الشبكة: `http://<عنوان-اللابتوب>:5000`.
العنوان يطبعه الخادم عند تشغيله. التخطيط يتكيّف مع الشاشات الصغيرة.
