# هبوب · HABOOB

**منظومة الراحة الحرارية للمساحات الخارجية في إكسبو 2030 الرياض**
تقيس ما يشعر به الضيف، وتحوّله إلى قرار تشغيلي.

> هاكثون إكسبو 2030 · التحدي 2.3: الراحة الحرارية في المناطق الخارجية · مسار الاستدامة والأثر البيئي

*HABOOB is a human-height sensing pole plus an analytics platform that turns weather readings into per-zone heat-stress (WBGT) flags and actionable cooling recommendations for Expo 2030 Riyadh outdoor operators.*

---

## المشكلة

يعمل مشغلو المساحات الخارجية في إكسبو اليوم بصورة لحظية ناقصة:

- **حرارة الهواء وحدها لا تعكس إحساس الضيف.** الشمس والرطوبة والرياح والظل تغيّر كيف يشعر الإنسان بالحر.
- **نقاط القياس قليلة.** الساحة المكشوفة والمظللة المجاورة لها قد يفرق إحساس الضيف فيهما بعدة درجات، فالقراءة الواحدة لا تمثّل الموقع.
- **التدخل متأخر.** أجهزة التلطيف (الرذاذ والتبريد والمراوح) تعمل بجداول ثابتة دون قياس أثرها، ويُكتشف الحر بعد أن يشعر به الضيف.

## الفكرة والهدف

**هبوب** عمود استشعار بارتفاع الإنسان في كل منطقة، ومنصة تحليل وواجهة للمشغل:

| المكوّن | الدور |
|---|---|
| **عمود الاستشعار** | يقيس الحرارة والرطوبة والرياح والإضاءة بارتفاع الإنسان بغلاف يحمل نقش السدو يمكن تخصيصه لهوية كل منطقة |
| **منصة التحليل** | تحسب مؤشر الإجهاد الحراري **WBGT** بطريقة Liljegren، وتصنّف المنطقة بعلم إجهاد (5 أعلام) مقابل حد ISO 7243 (29 °م للضيوف)، وتفسّر السبب |
| **واجهة المشغل** | خريطة حية بحالة المناطق، وتوصية بالإجراء المناسب مع أثره المتوقع، وأتمتة ما يمكن أتمتته، وإسناد مهام التشغيل والصيانة |

**الهدف:** الانتقال من «كم تبلغ الحرارة؟» إلى «ما القرار المناسب لهذه المنطقة الآن؟»، وتشغيل أجهزة التلطيف عند الحاجة وفي المكان الصحيح، بما يدعم راحة الضيف واستدامة الموارد.

## كيف تعمل

```
عمود ESP32 + الحساسات ──(JSON كل 5 ثوانٍ، Wi-Fi أو USB)──▶ خادم Python
      DHT22 · مقياس رياح · VEML7700              │ تحقق + معايرة + SQLite
                                                  ▼
                              وحدة الذكاء الاصطناعي: WBGT ← علم الإجهاد ← التفسير والتوصية
                                                  ▼
                                      منصة المشغل (خريطة، توصيات، مهام)
```

## التشغيل السريع (بلا عتاد)

```bash
cd src
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests          # اختبارات وحدة AI
python3 02_server_backend/app.py --simulate --port 5050
```

ثم افتح `http://localhost:5050` لمنصة التشغيل، و`http://localhost:5050/bench/` لموقع اختبار الحساسات.
لبرنامج العقدة: انسخ `src/01_firmware_esp32/sensor_node/secrets.example.h` باسم `secrets.h` واكتب بيانات شبكتك (الملف مستثنى من المستودع).

## التقنيات

ESP32 (Arduino) · DHT22 · مقياس رياح كأسي عبر ADS1115 · VEML7700 · شاشة ST7789V2 · Python · SQLite · WBGT (Liljegren) · ISO 7243 · HTML/JS

## الحالة الحالية

- الخادم والمنصة ووحدة AI وجسر USB مُختبرة بلا عتاد (محاكاة واختبارات آلية).
- **برنامج ESP32 لم يُجرَّب بعد على العتاد الحقيقي**، ومعاملات معايرة الرياح مؤقتة حتى المعايرة بمقياس مرجعي.
- الكرة الحرارية والبطارية مؤجلة في هذا الإصدار؛ يُقدَّر الإشعاع من حساس الإضاءة.
